# 動画編集（iPhone 用 Web アプリ）

iPhone の Safari で動く、CapCut の簡易版のような動画編集アプリ。4K までの動画を読み込み、無制限に 4K / フルHD で書き出せる。
動画はすべて端末内で処理し、外部へは送信しない。AI も使わない。ビルドは不要（素の HTML/JS）。

## できること

| 機能 | 内容 |
|---|---|
| 複数の動画 | 複数選ぶと選んだ順につなげる。後から「動画追加」やタイムライン末尾の「＋」で後ろに追加。クリップごとに分割・並べ替え・複製・削除・速度・音量 |
| 合体 | 「後ろと合体」で隣のクリップと1つのかたまりにする（同じ動画の続きなら1本のクリップに戻る）。「合体を解除」で元に戻す |
| クリップで分けて書き出し | 書き出し設定で選ぶと、かたまりごとに別々のファイルで書き出す（文字・音楽・重ねた素材もその時間の分だけ入る） |
| 音声補正 | ライブEQ の機能（自動EQ・効き具合・プリセット・5つのスライダー・詳細EQ・ドラムコンプ・大音量）。動画クリップを選ぶか「音声補正」から開く。原音/補正後の聞き比べ |
| 音のエフェクト | リバーブ・エコー・ひずみ・ステレオ拡張。プリセット（豪華ライブ・弾き語り・ホール・ロック・エコー） |
| 重ねる | 画像・動画をメイン動画の上に重ねる（ワイプ）。位置・大きさ・回転・不透明度・形（四角/角丸/円）・縁取り・影・左右反転・出かた・動画の音量 |
| 文字入れ | 日本語・英語フォント17種（ヒラギノ＋Google Fonts の無料フォント）。縁取り2重・影・グラデーション・背景の帯。YouTube 風のプリセット10種。ドラッグで移動、2本指で拡大。出かたのアニメーション（ポン・フェード・下から・タイプ） |
| 読み上げ | iPhone 内蔵の声で試し聞き。動画に入れる音声は「ショートカット」App の「テキストから音声を作成」で作って読み込む（同じ文章を字幕として自動追加できる） |
| 切り抜き | 16:9 / 9:16 / 1:1 / 4:5 / 4:3 / 3:4 / 自由。拡大せず元の画素のまま書き出す |
| 速度 | 0.25〜4倍。声の高さを保つ（WSOLA）かどうかを選べる |
| 音声 | 音楽・効果音を何本でも追加。タイムラインで位置・長さを調整、音量・フェード、元の動画の音量とのバランス |
| エフェクト | ランダムな揺れ（強さ・速さ・回転・方向・なめらか/ガクガク・文字も揺らすか）、ズーム、フラッシュ、フェード |
| その他 | トリミング、分割・複製・削除、元に戻す / やり直す。縦横比が違う動画は「全体を表示（黒い帯）」か「画面いっぱい」を選べる |
| 書き出し | 元の画質（最大 3840×2160）/ 1080p / 720p、フレームレート、H.264 / HEVC、高画質 / 最高画質 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `js/app.js` | 画面の動作（プレビュー、タイムライン、各パネル、書き出し画面） |
| `js/project.js` | 編集データの構造と計算（時間の変換、出力サイズ、文字のプリセットなど） |
| `js/render.js` | 1フレームの描画（切り抜き・エフェクト・文字）。プレビューと書き出しで共用 |
| `js/fonts.js` | フォント一覧と読み込み |
| `js/audio.js` | 音声のデコード、速度変更、ミックス、波形 |
| `js/media.js` | 動画の読み込みと書き出し（[Mediabunny](https://mediabunny.dev/) + WebCodecs） |
| `js/dsp.js` | 音声補正とエフェクトの処理（ライブEQ から移植）。試聴・解析・書き出しで共用 |
| `js/fx-worklet.js` | 試聴用。再生中の動画の音声にリアルタイムで補正をかける（AudioWorklet） |
| `js/fx-worker.js` | 自動EQの解析と音量合わせの計算（別スレッド） |
| `js/vendor/mediabunny.min.mjs` | Mediabunny 1.61.3（MPL-2.0、`mediabunny.LICENSE`） |
| `sw.js` | オフライン用（アプリ本体と一度使ったフォントをキャッシュ） |

## ローカルで動かす

```bash
python3 -m http.server 8765 --directory .
```

PC のブラウザで http://localhost:8765 を開く。iPhone から使うには HTTPS が必要なので、GitHub Pages などで公開する。

## GitHub Pages で公開する（無料）

1. GitHub で新しいリポジトリを作成する（Public）
2. 「Add file → Upload files」から、このフォルダの中身をドラッグ＆ドロップする
3. Settings → Pages → Branch を `main` / `(root)` にして保存する
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる。iPhone の Safari で開き、共有 →「ホーム画面に追加」する

## 読み上げ用ショートカットの作り方（1回だけ）

1. 「ショートカット」App で「＋」→ 新規作成
2. アクション「テキストから音声を作成」（英語: Make Spoken Audio from Text）を追加し、テキストを「ショートカットの入力」にする
3. 声（Kyoko、Otoya など）と速さを選ぶ。「毎回尋ねる」にすると毎回選べる
4. 「ファイルを保存」アクションを追加
5. 名前を「読み上げ音声」にして保存（アプリ側の設定で名前は変えられる）

声は「設定 → アクセシビリティ → 読み上げコンテンツ → 声」から追加できる。

## 注意

- 書き出しは再エンコードになる。画質を落とさないよう、ビットレートは iPhone のカメラと同等以上（4K30 の H.264 で約 42Mbps、最高画質で約 70Mbps）にしている
- HDR で撮影した動画は、SDR（通常の色域）で書き出される
- 書き出したファイルは一度メモリ上に置くので、4K 60fps なら 3分程度までが目安
- 端末が AAC の音声エンコードに対応していない場合は、MOV 形式（音声は無圧縮 PCM）で書き出す
- 編集内容は保存されない（アプリを閉じると消える）
